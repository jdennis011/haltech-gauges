# Base recordings

Recordings made on a hub (Live data tab, Record, then Download) that the online copy
and any hub's page can play from the site's library. Drop a file here; the site build
lists every `*.json` in this folder. The header line may carry a `description`.

Planned set: idle, a standard acceleration from a stop, a steady highway minute, a
cold start, so faces can be tested against real data.
